An entry for the [Dad Joke Showdown](https://make.fun/competitions/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on [make.fun](https://make.fun): one original dad joke, written to be told out loud at the dinner table.

## The joke

> People ask how I afford three kids. Easy — I just keep raising them: the cost, the noise, and my blood pressure.

## How it works

`main.py` is pure Python standard library — no network, no clock, no randomness. It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Two runs write byte-identical files.
